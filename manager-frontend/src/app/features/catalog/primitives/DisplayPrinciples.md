### Display Principles

A list of principles that govern the display of information in the application.

### Display of JSON objects

1. JSON objects are initially displays as a single line with several typical components (that are displayed with a standard font and are not editable) with a eye button that when pressed displays the full JSON object in a more detailed format (that can be edited)

### SKILL

Convert these instructions to a skill for the general display of a JSON object. The user is queries about which values to use. 

### Subclasses of ParameterSpecification

The single line display is the label and the units of the parameter.
For ParameterSpecificationEnthalpy the label is ParameterLabelEnthalpy and the units are UnitsOfMolarEnthalpy. These are displayed on the first line.

This applies to ParameterSpecificationEnthalpy, ParameterSpecificationEntropy, ParameterSpecificationHDisassociationEnergy, ParameterSpecificationHeatCapacity, ParameterSpecificationStructureVibrationFrequency, ParameterSpecificationTemperature



### subclasses of JThermodynamicMolarQuantities

When the eye button is pressed, then the ParameterSpecification is shown (also with the first line.)

User Data Deletion Instructions

REACT Cloud — Chemical Reaction Mechanism Platform

REACT Cloud uses Firebase Authentication (including Facebook Login) to authenticate users and store personal chemical databases and mechanism generation logs.

How to Remove Facebook App Access

  1. Log in to your Facebook account and go to Settings & Privacy → Settings.
  2. Select Apps and Websites in the left navigation menu.
  3. Find REACT Cloud in the list of active apps and click Remove.

How to Request Complete Deletion of Your REACT Cloud Data

To permanently delete your REACT Cloud user profile, personal database records (molecules, substructures, reaction patterns, pathways), and stored execution artifacts from Google Cloud Firestore and Cloud Storage:

  1. Send an email to edward.blurock@gmail.com with the subject REACT Cloud Data Deletion Request.
  2. Include the email address or User ID associated with your REACT Cloud account.

All personal workspace data, logs, and authentication records associated with your account will be permanently deleted within 7 business days, and you will receive confirmation once the deletion is complete.

The project goal is to containerize the REACT chemistry system (a 12-year-old C codebase) for deployment on Google Cloud Run. The overall strategy is a multi-stage Docker build producing a runtime image that can run chemdb either in CLI mode or via an HTTP server wrapper on port 8080. Work has proceeded through 6 phases: project setup, Dockerfile creation, C code modernization, HTTP entrypoint wrapper, Docker build validation on Linux, and production/endpoint enhancements.

Project Summary

This project modernized and containerized the legacy REACT chemistry system for production use on Google Cloud Run. The work included Linux compatibility fixes for C builds, a dual-mode container entrypoint, and an HTTP API wrapper that can execute direct commands or input-template workflows.

  • Multi-stage Docker build with runtime dependencies only.
  • Database initialization baked into image build via make all and make install.
  • API endpoints: /health, /api/run, and /api/run-input.
  • Cloud Run deployment pipeline through Artifact Registry.

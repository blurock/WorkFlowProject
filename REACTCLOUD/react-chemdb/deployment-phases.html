Cloud Run Deployment Path

The release path uses Artifact Registry image hosting plus gcloud run deploy. Build with linux/amd64 when running from Apple Silicon so Cloud Run can run the image. 

export PROJECT_ID="blurock-database"
export REGION="us-central1"
export SERVICE_NAME="react-chemdb"
export REPO_NAME="react-images"
export IMAGE_URI="$REGION-docker.pkg.dev/$PROJECT_ID/$REPO_NAME/$SERVICE_NAME:v1-amd64"

docker buildx build --platform linux/amd64 -t "$IMAGE_URI" --push .

gcloud run deploy "$SERVICE_NAME" \
  --image "$IMAGE_URI" \
  --platform managed \
  --region "$REGION" \
  --allow-unauthenticated \
  --memory 2Gi \
  --timeout 3600 \
  --cpu 2 \
  --concurrency 1 \
  --max-instances 10

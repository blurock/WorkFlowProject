Branch Strategy

Keep deployment work on the dedicated branch blurock-reactcloudrun-setup and push frequently.

Backup Commands

git checkout blurock-reactcloudrun-setup
git status
git add .
git commit -m "Describe the deployment/documentation changes"
git push -u origin blurock-reactcloudrun-setup

Create a Pull Request

gh pr create \
  --base master \
  --head blurock-reactcloudrun-setup \
  --title "REACT Cloud Run and hosting docs updates" \
  --body "Includes Cloud Run deployment updates and Firebase Hosting documentation site."

Recommended Checks Before Push

  • Ensure no secrets are committed (.env, keys, tokens).
  • Verify Cloud Run deployment commands in docs still match current project settings.
  • Use clear commit messages tied to deployment phases.
